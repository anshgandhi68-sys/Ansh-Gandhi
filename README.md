## ⚡ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Static Site Generation + Edge API)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (Weights 400, 500, 600 strictly enforced)
- **Animations:** [GSAP 3.12](https://greensock.com/gsap/) with ScrollTrigger
- **Icons:** [Iconify](https://iconify.design/) (Solar Icon Family)
- **Deployment:** Vercel

## 🎨 Visual Design System

- **Pale Butter (`#FFF8E6`)**: Warm base background with 24px diagonal grid `linear-gradient(135deg, rgba(42,31,20,.035))`
- **Ink (`#2A1F14`)**: Editorial headings and structure borders (10% and 25% opacity)
- **Kelp (`#2F6B4F`)**: Editorial deep-tech and contact section background
- **Apricot (`#FF9F5A`) & Coral (`#FF6F61`)**: Interactive accents and dimensional highlights
- **Lemon (`#FFE27A`)**: Verified markers and strategic focal points
- **Selection (`#FFE2C8`)**: High-craft custom text selection
- **Visual Frame:** Fixed 16px inset boundary with vertical guide lines at `16.666%` and `50%`

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node.js 20 / 22 / 26)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/anshgandhi68-sys/Ansh-Gandhi.git
cd Ansh-Gandhi

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build

```bash
npm run build
npm run start
```
